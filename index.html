Inicia la aplicación con Vite

Abriste esta carpeta con Live Server. La aplicación ya está configurada para ejecutarse en Vite.

Abrir la aplicación
  1. Abre una terminal en la carpeta del proyecto.
  2. Ejecuta npm install (solo la primera vez).
  3. Ejecuta npm run dev.
  4. Abre http://localhost:3001 (el puerto ya está fijado).

Si Windows no reconoce npm, instala Node.js LTS y vuelve a abrir la terminal.
